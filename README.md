# bookworm-ai-swot-analysis

SWOT analysis of Bookworm.AI for Chase Coaching for Impact, with competitors and what sets Bookworm apart.

A plain static site, no build step:

- `index.html` is the page.
- `Bookworm-SWOT-Analysis.pdf` is the downloadable copy.
- `robots.txt` and a `noindex` tag ask search engines to leave it out.

Deploy on Vercel: import this repository, leave the framework as "Other", and deploy.
